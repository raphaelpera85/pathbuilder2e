# Grafo de conhecimento RPG

`graph.json` é um índice local versionado para navegar pelas opções catalogadas, edições, fontes e páginas. É compilado com `npm run catalog:knowledge-graph` a partir de `catalog/snapshots`, das listas de magias/domínios D&D 3.5 tipadas e do inventário estático `book-inventory.json`; não consulta Supabase nem depende do Graphify. `npm run audit:knowledge-graph` verifica sincronização e arestas órfãs. Os registros originais continuam sendo a fonte dos dados e das descrições.

Cada entidade é identificada por sistema + ruleset + categoria + ID. Assim, nomes iguais em Pathfinder, D&D e Tormenta — ou em edições diferentes — não são fundidos. `listed_on` aponta para a página de lista/fonte (`source_page`); `described_on` e `description_continues_on` apontam para páginas descritivas apenas quando o registro informa `detailsPage`/`detailsPageEnd`. Ausência de uma dessas referências é uma lacuna, não uma página inferida.

Nós atuais: sistema, ruleset, livro, página, entrada catalogada e texto de pré-requisito. Arestas: edição pertence ao sistema, entrada disponível na edição, fonte bibliográfica, página de lista, página descritiva e pré-requisito. As relações textuais ainda não pretendem resolver pré-requisitos em referências semânticas entre entidades.

`book-inventory.json` contém os PDFs de livros/módulos legíveis encontrados em `I:\Meu Drive\Livros RPG`, com caminho relativo, paginação confirmada pelo parser de PDF, sistema quando identificável e status `inventory_only`. A pasta `Pathfinder/Mapas` (151 PDFs de mapas e tiles) e fichas não são tratadas como livros de regras. A auditoria encontrou zero arquivos TXT pareados, por isso a próxima fase exige extração/OCR e conferência visual página a página. Pathfinder sem edição inequívoca aponta para sistemas candidatos, não para uma edição presumida. Para atualizar o inventário após nova auditoria local, use `npm run audit:books -- --write-inventory`; o comando não copia nem armazena os PDFs no Git.

A curadoria manual deve validar sumários, índices e referências nas fontes primárias, respeitando direitos autorais; descrições extensas não devem ser duplicadas no grafo. `coverage.recordsWithoutBook`, `coverage.recordsWithoutSourcePage`, `coverage.recordsWithoutDescriptionPage` e `coverage.summaryOnlyRecords` expõem lacunas dos registros catalogados. A contagem de livros inventariados não deve ser confundida com completude de conteúdo: o grafo permanece em construção até as entidades e páginas internas de cada obra serem revisadas.
